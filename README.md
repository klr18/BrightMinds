# 📚 Веб-приложение для онлайн-обучения

## 📖 Описание
Веб-приложение, разработанное в рамках дипломного проекта.  
Сервис предназначен для организации онлайн-обучения и обеспечивает взаимодействие между студентами и преподавателями.

## ⚙️ Основной функционал
- Регистрация и авторизация пользователей  
- Добавление и просмотр курсов и уроков  
- Подписка на курсы  
- Прохождение тестов  
- Админ-панель для управления контентом  
- Обратная связь с администрацией  
- Просмотр профилей пользователей и статистики  
- Редактирование личного аккаунта  

## 🛠 Используемые технологии
- Python (Django)  
- HTML, CSS, Bootstrap  
- JavaScript  

## 🎯 Цель проекта
Освоение разработки веб-приложений и создание системы онлайн-обучения с базовым функционалом.

## ▶️ Запуск проекта
1. Клонировать репозиторий:
   git clone https://github.com/klr18/BrightMinds.git
   
2. Перейти в папку проекта:
   cd BrightMinds

3. Установить зависимости:
   pip install -r requirements.txt

4. Запустить сервер:
   python manage.py runserver
